- `peter` 是集成基线，不是已经发布的小程序。当前仓库 `project.config.json` 使用**小程序测试号**，`miniprogramRoot` 指向 `build/production-miniprogram/`；“production”指代码包模式，不是微信正式账号或生产环境。
- 用户选择个人主体作为目标，但个人账号项目在开发者工具里尚无“已创建”证据；用户最新只展示了**新建项目表单**，未确认点击创建。不可把测试号 AppID 直接写成个人目标 AppID。
- 后端已在仓库中，S-01～S-03 是 `DONE_LOCAL_TEST`，不是公网部署。无已核实的 HTTPS API、服务器/域名、受控音频地址，也无真实微信登录或跨设备真机完成证据。
- S-04 隔离 PostgreSQL/真实 HTTP 双会话 smoke 已通过；D1～D7 双真机、弱网、退出/重装仍待验收。`X-02` 的 iPhone 音频真机项仍阻断；阶段 0 是 `NO-GO`，不得发布内容或开启支付。
- 本交接**不规定任务优先级或执行顺序**。未完成工作由接手同事与项目负责人排期；完成条件见第 5 节。

## 3. 音频与 iPhone 现场

- 正式目录的 Peter Rabbit 音频 URL 在 `miniprogram/modules/catalog/catalog.json`；当前指向 Archive.org 直链。仓库保存本地测试文件 `preview/audio/peter-rabbit-librivox.mp3`（2,580,786 字节），来源和使用限制见 `preview/audio/SOURCE.md`。该文件不在小程序主包中，也没有可供手机访问的受控 HTTPS 地址。
- 2026-09-24 的 X-02 iPhone 记录已复现播放停在 `00:00`；2026-10-09 测试号新预览里用户确认字幕出现，进度条不动并提示音频加载失败。同一 MP3 链接在该 iPhone Safari **打不开**。这证明该地址不能用于该设备/网络的当前测试，但不能排除播放器另有问题。
- 用户另称“无法拨动字幕”，尚未明确是指字幕区域手势滚动还是进度条拖动。字幕区现有设计为自动跟随、`overflow:hidden`，不能把用户反馈直接归为已修复或误操作。
- 当前开发版诊断返回“音频错误码：未知”。不要凭该文本声称 10002/10003 或具体服务器错误。
- 任何替换音源都要先核对权利与部署边界，再在 iPhone Safari 和微信预览中分别验证音频可达、播放、进度及 X-02 D-01～D-09；仅换成一个 URL 不构成验收通过。

- 当前测试号可生成开发预览二维码，但微信开发者工具查询其云环境明确返回 `ret:-601059`、“测试号不能使用云服务”。

- 本机生成的预览二维码、工具信息、`project.private.config.json` 和其他凭据/产物不应提交。切换账号时使用独立项目目录，保留当前测试号 `project.config.json`；不要在未经核验时覆盖或上传到个人账号。
