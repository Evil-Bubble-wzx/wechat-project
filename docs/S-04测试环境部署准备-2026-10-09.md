## 2. 最小测试环境目标

仅用于隔离测试，不接入真实支付或正式用户数据。需要以下组件形成一条完整链路：

1. 对手机可访问的 HTTPS API 地址，前端只配置 API 根地址；反向代理将请求转给非公网直开的 Fastify API。
2. API、Worker、PostgreSQL、Redis、对象存储与音频资源，彼此使用隔离的测试配置、数据与访问权限。
3. 受控配置提供真实微信测试身份所需凭据及独立生成的服务端密钥；不入 Git、文档、截图或聊天。此前暴露的测试号密钥不得沿用。
4. 数据库迁移、`/health/live`、`/health/ready`、版本号、匿名请求 ID、备份与基本日志可验证；对公网只开放必需入口。
5. 微信后台按实际使用的目标小程序账号配置 API 与资源合法域名，随后再做 Android/iPhone 真机测试。测试号开发预览不能代替目标账号验收。
