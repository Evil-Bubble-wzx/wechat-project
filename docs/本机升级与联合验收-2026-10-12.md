## 操作入口

在开发者工具打开 `build/commerce-local-primary`，点击编译：

- Home：动态目录；打开 Peter 检查字幕、词卡、播放及暂停续播。
- Me：检查既有积分/云历史、收藏和最近阅读。
- Quiz：当前内容为内部 v2；新练习与旧记录按版本区分。
- 模拟内容包与订单：原已授权订单仍可打开测试正文；全程不涉及真实资金。

primary/isolation 为本机专用项目，另一个手机不能访问 localhost。Android 本轮暂缓；临时网关和手机资源送达未在本轮扩展。

## 复现命令

从仓库根目录执行，Node 24+；私有 env-file 需先由环境准备工具生成。

```powershell
node --env-file=backend/.env.device-local backend/ops/backup-device-local.cjs backup
node --env-file=backend/.env.device-local backend/src/database/cli.ts up
node --env-file=backend/.env.device-local backend/scripts/upgrade-device-content.ts
node tools/build-commerce-local-preview.cjs
node --env-file=backend/.env.device-local tools/commerce-local-ui-check.cjs
node --env-file=backend/.env.device-local backend/ops/backup-device-local.cjs verify PRIVATE_BACKUP_DIRECTORY
```

必须先取得备份恢复通过结果，再升级。v2 再次执行会核验既有摘要后保持不变，不覆盖不同内容。API/worker 的启动与 PID 身份核对沿用本机环境运行方式，凭据和备份不上传。
