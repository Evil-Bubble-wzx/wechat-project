# S-04 受限 API 本机验证

> 2026-10-10；已实现、本机验证，并经用户确认建立临时受限 HTTPS；不是正式微信身份或手机验收。

用户确认：只允许两个模拟账号，primary 日常联调、isolation 验证切换与隔离；凭据随机生成，仅存本机忽略文件及独立开发包。Android 验收暂缓。公开前须检查具体范围。

## 已实现的边界

`tools/device-api-gateway.cjs` 只监听 `127.0.0.1:4181`，上游固定 `127.0.0.1:3100`。每个请求必须带对应账号的随机 `X-Device-Test-Key`，登录身份固定映射，不能用请求体指定其他身份。访问与刷新令牌在代理内存中绑定账号，代理重启后须重新登录。凭据不写日志。

仅允许以下方法和路径（共同前缀 `/api/v1`）：

| 方法 | 路径 |
| --- | --- |
| POST | `/session/wechat`、`/session/refresh` |
| DELETE | `/session/current` |
| GET | `/me`、`/me/progress`、`/me/progress/:pieceId` |
| PUT | `/me/progress/:pieceId` |
| POST | `/me/words/sync`、`/me/quiz-attempts` |
| GET | `/me/learning-score`、`/ranking-options`、`/rankings`、`/rankings/:participantId/quizzes` |

本轮不放行历史导入、远程目录/manifest、后台导入、监控或管理接口。客户端自动历史导入如触发会失败，不能把该测试包作为完整产品使用。数据库尚没有发布的彼得兔服务端内容，写入进度和答题的完整联调还需种子/内容导入准备；不能以只读接口通过宣称所有写接口已经通过代理验收。

代理拒绝绝对 URL、编码路径和穿越，JSON 写入最大 256 KiB，每账号每分钟最多 120 请求，令牌映射有上限。刷新同幂等键可恢复，换键重放拒绝；下游另有业务限制与限流。登录使用由凭据和幂等键生成的稳定票据，不改变真实微信 provider。

## 私有文件与操作

```powershell
node tools/prepare-device-gateway.cjs
node tools/device-api-gateway.cjs
node tools/build-device-api-preview.cjs
node tools/device-gateway-smoke.cjs
```

凭据在 `.cache/device-local/gateway.json`；两个包在 `build/device-api-primary/` 和 `build/device-api-isolation/`，均被 Git 忽略。包内私有配置仅启用于开发环境，体验/发布环境禁用网络。源目录没有写入密钥或临时 API 地址。包只供指定测试人员，不上传正式版本或分发；localhost 地址只适用于电脑，不能直接用于手机。

当前代理隐藏后台运行，PID 与日志在 `.cache/device-local/gateway.pid`、`gateway.log`、`gateway-error.log`；停止前核对进程身份，关闭它不会停止本机 API。没有建立 4181 隧道；此前公开的单 MP3 入口保持独立。

## 验证结果和下一步

实际本机 API smoke 通过：无凭据、未知路由、无令牌、跨账号访问/刷新均拒绝；任意请求身份固定映射；登录同账号稳定、不同账号隔离；读取 me/进度/积分/排行配置；刷新同键重试成功、异键拒绝；退出后拒绝读取。配置同名账号、非法 JSON、非 JSON 内容类型、超大请求及编码路径也拒绝。两个私有包均通过 10 路由静态检查。

下一步先准备测试内容并验证进度、生词和答题写路径，以及客户端历史导入停点，再决定是否建立仅指向此代理的临时 HTTPS 隧道；公开时需告知持有私有包凭据即可访问对应模拟账号，地址临时且电脑停机会失效。没有真实用户数据、真实微信登录或正式发布结论。

## 真实内容与写入联调完成记录

随后用户确认使用当前彼得兔真实内容并在私有包关闭历史导入。本机执行 `backend/scripts/seed-device-content.cjs`，仅允许 local 环境、专用 55433 数据库与 59000 对象存储。六类实际资源（音频、字幕、正文、词汇、题目、元数据）已保存，音频哈希核对源 manifest；真实 10 题的题目、选项、答案与客户端一致。原审核材料保留在资源包，来源 gate、阻断项与哈希另记录于 `.cache/device-local/content-fixture.json`。

数据库中的 published/publishable 仅作为现有服务读取内部样本的条件，**不表示源内容取得发布批准**。源 manifest 仍 needs_review/publishable:false，C-03 外审等阻断没有关闭，也没有修改正式发布内容。

两个私有构建的 `openLocalImport` 和 `submitLocalImport` 被单独阻断并显示本轮不导入历史数据的提示；生产源码行为不变。本次检查发现源码没有自动导入历史数据，原先“自动导入”说法不准确：它实际是用户明确同意后提交的入口。私有包暂时关闭整个入口。

`tools/device-content-write-smoke.cjs` 使用生成的私有客户端模块、wx transport 的 Node HTTP 适配、临时 loopback 受限代理及持久本机 API。通过：

- 真实 piece/version 的进度写入、幂等重放与第二会话读取。
- 实际词汇 entryId/vocabKey 的保存、幂等回执、游标拉取与删除。
- 真实 10 题提交，服务端验证 100 分；重放后总积分不增加。
- 同账号第二会话积分相同；另一模拟账号进度和生词不串号。
- 两个私有包的 10 路由静态检查通过。

测试中仅 primary 产生样本学习记录，isolation 保持无进度/生词。测试数据不是用户真实学习结果。尚未进行手机接口测试；API 公网入口仍未建立。下一步可审阅上述路由和私有凭据范围后确认临时 HTTPS 开放，再配置手机私有预览包。

## 经确认的临时 HTTPS

用户确认以上范围后，新增独立 API 隧道，只转发 `127.0.0.1:4181` 受限代理；没有直连 3100 后端、数据库或管理入口。隧道 PID、日志在 `.cache/device-local/api-tunnel.pid`、`api-tunnel-error.log`。停止该进程关闭 API 公网入口；音频隧道独立。

HTTPS 实测：匿名 `/me` 401；带测试凭据的管理路径 404；指定模拟身份登录 201、积分读取 200、退出 200。客户端私有构建配置该临时 HTTPS API 和已经 iPhone 测过的单音频地址，primary/isolation 两包静态检查均通过 10 路由。构建脚本支持显式传入两个临时地址，不修改正式客户端配置。包内带随机凭据，只供指定测试者。

primary 开发预览二维码写入 `.cache/device-local/api-primary-preview.png`，用户扫码后先同意并登录，再听 10 秒、保存一个生词、完成一次答题，查看同步状态与积分。再次退出登录/重新登录应保留服务端数据。此前 100 分、少量进度和生词删除是内部联调样本，不能计作用户真实学习证据。等待手机反馈；当前没有真机 API 成功结论，Android 继续暂缓。

用户首轮反馈“微信登录失败，请稍后重试”。检查时后端尚无对应新请求，不能判断手机网络请求是否发出。发现开发 stub 登录仍先调用真实 wx.login，已移除这项不必要依赖；真实登录流程继续调用 wx.login。新增回归测试明确模拟登录不依赖平台服务，adapter 5/5 通过。

私有构建增加仅显示分类的登录诊断（域名限制、网络失败、超时、凭据、响应格式等），不展示凭据、原始 URL 或响应。重新生成 v2 私有预览码 `.cache/device-local/api-primary-preview-v2.png`，等待手机复测；此修复不证明原失败唯一原因，也未关闭合法域名或证书检查。

用户复测诊断为“域名限制”。随后用户在个人账号后台保存临时 API request 合法域名，并提供目标 AppID `wxef246c6a495e4030`。私有构建按此 AppID 重新生成，默认仓库 project.config.json 仍保持测试号。新预览码 `.cache/device-local/personal-api-preview.png` 仅供个人账号开发验证；后台依然为模拟身份，不使用真实 AppSecret，服务类目与正式发布门槛仍未关闭。
