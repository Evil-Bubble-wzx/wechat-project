## 2. 排行算法口径

排行榜最终指标是服务端生成的 0～1000 综合算法分，不是完成 Quiz 的书本数。`quiz-score-v1` 当前权重为：

- 完成 Quiz 的不同书本数：30%；
- 有效词量：15%；
- 贝叶斯校正正确率：25%；
- 阅读挑战度：15%；
- 成长幅度：10%；
- 题材广度：5%。

客户端不得提交、计算或覆盖最终排名分数。完整规则见 `backend/docs/adr/0003-ranking-score-v1.md`。

## 3. 数据库与内容处理

- 当前共有 6 条成对 migration，创建 27 张业务表和 `schema_migrations`，并幂等写入 A/B 两个校区。

## 7. 本地启动与验收

先启动 Docker Desktop，然后执行：

```powershell
Set-Location -LiteralPath 'D:\小程序\backend'
npm install
docker compose up -d
npm run db:migrate
npm run start:api
```

另开终端启动 Worker：

```powershell
Set-Location -LiteralPath 'D:\小程序\backend'
npm run start:worker
```

关键检查与测试入口见 `backend/README.md`。只有 `/health/ready`、数据库、队列、内容导入、Quiz、排行和 X/B 联调全部通过，才可认为本地后端完整性复验完成。
