## 4. 官方接入依据与需要留存的证据

1. 微信支付《开发接入准备》要求完成小程序账号认证、申请支付权限、商户号与 AppID 授权绑定，并提示交易类小程序需满足相应运营规范：<https://pay.wechatpay.cn/doc/v3/merchant/4015459512>。
2. 微信支付《申请 JSAPI 支付权限指引（小程序支付场景）》说明可在商户平台核实权限，并要求填写已认证且主体匹配的小程序 AppID：<https://pay.wechatpay.cn/doc/v3/merchant/4012791895>。
3. 微信支付结果通知需要服务端验签；不得以客户端成功回调直接发权益：<https://pay.wechatpay.cn/doc/v3/merchant/4012791861>。

外部证据建议使用受控目录或项目管理系统保存，并在本表只填以下信息：

- 证据编号；
- 受控存储位置；
- 截图/文件日期；
- 核验人；
- 结论与有效期；
- 若是客服或审核答复，记录工单号和完整上下文。

## 5. 阶段 0 退出条件

只有同时满足以下条件，才能把阶段 0 标记为完成并排期阶段 1：

- G0-01 至 G0-05 均为 `PASS` 或有签字确认的 `N/A`；
- 首版商品、试读、售价和退款规则已冻结；
- 拟上线的每项内容在权利台账中均为 `APPROVED`，且内容 QA 可发布；
- 隐私与未成年人方案已和实际数据流对齐；
- 云环境、预算、运维、客服、退款和对账负责人已指定；
- Android 与 iPhone 的收费路径分别取得可复核结论；
- 项目负责人记录 GO 决策、日期和范围。
