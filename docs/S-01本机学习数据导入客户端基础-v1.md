## 1. 已完成范围

实现位于 `miniprogram/modules/sync/local-import.js`，测试位于 `tests/local-import.test.js`。本轮完成：

- 只接收调用方显式传入的正式本机 state，不自行读取或回写微信存储；
- 只生成进度、生词和 Quiz 三类候选；
- Demo、购买、优惠券、邀请、借阅、用户资料和权益字段出现时阻断整批；
- 对未知 piece、过期 schema、版本不匹配和损坏记录逐项排除并报告；
- 对规范化 JSON 计算 `s01-v1:<SHA-256>`，相同内容稳定得到相同 `snapshotId`；
- 提供摘要、显式同意、拒绝和单飞 mock 提交状态机；
- 写操作不自动重试，手动重试复用完全相同的 `snapshotId` 与 payload；
- mock 成功不写服务端确认、不删除本机数据、不标记真实导入完成。

## 2. 白名单与信任边界

### 2.1 进度

候选只保留：

- `pieceId`；
- `contentVersion`；
- `durationMs`；
- `checkpointMs`；
- `listenedRangesMs`；
- `updatedAt`。

收听区间转为整数毫秒，裁剪到音频时长，删除空区间，并按 50 ms 连续容差排序合并。客户端派生的 `completed`、`coverage`、`listenedSeconds`、`completionReason` 和实现路径 `audioKey` 不进入快照；服务端必须按可信证据自行计算。

### 2.2 生词

当前本机生词只有词面 `string[]`，没有 `vocabKey`、保存时间、版本或删除墓碑。因此只允许当前 Peter Rabbit 已审核可点击 token 的精确词面，候选格式为 `{surface}`，并声明：

`limitations.words = "surface_only"`

不会擅自改变大小写、还原词形或推断义项。完整 saved-words 同步和删除冲突属于 S-02/S-03 与 B 契约。

### 2.3 Quiz

只接受当前 `pieceId + contentVersion + quizVersion` 的 `schemaVersion:1`、`local_unverified` attempt，且题目和选项必须在当前正式题包内。候选保留：

- `attemptId`；
- work/piece/content/quiz 身份；
- `questionIds`；
- `selectedOptions`；
- 起止时间。

`score`、`mastery`、`title` 和本机状态全部剥离。相同 attemptId 与相同 payload 去重；相同 attemptId 出现不同 payload 时整批 `ready:false`，不替用户选择数据。

## 4. B 契约必须冻结

1. 固定 OpenAPI/JSON Schema 版本与 B 分支提交 SHA；
2. `POST /api/v1/me/local-import` 的正式请求和响应；
3. 以 `userId + snapshotId` 为幂等边界；
4. 逐项接受、拒绝和版本不兼容回执；
5. 进度证据的服务端可信计算；
6. 生词从 `surface_only` 升级到稳定词条 ID 的映射策略；
7. Quiz 服务端题库重判和 attempt 冲突处理；
8. 只有服务端明确回执后才允许客户端记录已导入；
9. 登录、退出、换账号、弱网、重复点击和重装测试。
