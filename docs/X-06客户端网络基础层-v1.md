# X-06 客户端网络基础层 v1

> 状态：`DONE`
> 完成日期：2026-09-24
> 范围：仅通用客户端网络基础设施，不代表真实后端已接入

## 1. 完成范围

本任务在不猜测 B 端字段、域名和业务语义的前提下，建立后续联调可以复用的客户端边界：

- `miniprogram/services/network/client.js`：默认关闭的 API client；
- `miniprogram/services/network/wx-transport.js`：可注入的微信 `wx.request` transport；
- `miniprogram/services/network/token-store.js`：仅内存 access token；
- `miniprogram/services/network/errors.js`：稳定客户端错误类型和安全 UI 文案；
- `tests/network-client.test.js`：16 项边界测试。

客户端只有在调用方明确传入 `enabled:true`、合法 `baseUrl` 和 transport 时才发起请求。正式地址只允许 HTTPS；本地开发仅允许 `http://localhost` 或 `http://127.0.0.1`。仓库不保存真实 API 域名或环境密钥。

## 2. 已冻结行为

### 2.1 会话与敏感数据

- access token 只保存在当前 JavaScript 进程内存；
- `logout()` 立即清除 access token，并使正在进行的刷新结果失效；
- 不使用 `wx.setStorageSync` 保存 token；
- 不实现或持久化 refresh token；
- 可注入的 `refreshSession` 只定义刷新协作边界，多个并发 401 共用一次刷新；
- 刷新失败立即清除会话，不再把原业务 GET 当作普通网络失败重复发送；
- 错误对象和面向用户的文案不包含 token。

refresh token 的轮换、保存方式和有效期必须由 B 的 OpenAPI/安全评审冻结后再实现。

### 2.2 超时、取消与重试

- 默认超时为 10 秒，可由测试或调用方覆盖；
- 支持 `AbortSignal` 主动取消；微信 transport 会调用 request task 的 `abort()`；
- 只自动重试 `GET`、`HEAD`；
- 仅网络失败、超时、HTTP 502/503/504 可重试；
- 默认最多重试 2 次，使用指数退避和抖动；
- `POST` 等写请求默认不重试；
- 401 的会话刷新最多尝试一次，不进入普通重试循环。

后续即使 B 提供幂等键，写请求重试也必须按具体端点显式评审，不能更改全局默认值。

### 2.3 错误与追踪

客户端错误类型固定为：

- `disabled`；
- `invalid_config`；
- `timeout`；
- `network`；
- `cancelled`；
- `http`；
- `unauthorized`；
- `contract`；
- `server`。

响应中的 `X-Request-Id` 或 JSON `requestId` 会原样保留；`error.code` 保存为 `serverCode`，但当前不猜测任何服务端错误码含义。UI 只能通过 `toUserMessage()` 获取安全的通用中文提示，不能直接展示服务端内部文案。

## 3. 明确未完成

以下事项不属于 X-06 的完成范围，也没有被 mock 冒充：

- `wx.login` 与 `POST /api/v1/session/wechat`；
- access/refresh token 的真实响应 Schema、有效期和轮换；
- `GET /me`、works、work、manifest、Quiz 等业务适配器；
- dev/test 的真实 API 域名和微信合法域名；
- 具体稳定错误码到页面行为的映射；
- 跨设备同步、订单、支付、权益或生产开关；
- 真实后端联调、弱网真机证据和生产验收。

因此当前小程序仍运行原有本地阅读路径，网络基础层没有在 `app.js` 或页面中启用。

## 4. B 交付后的接入顺序

1. 核对 B 分支提供的契约版本和提交 SHA；
2. 校验 OpenAPI、JSON Schema、错误码表与 test 环境地址；
3. 冻结 session 的 token 生命周期和客户端保存策略；
4. 在通用 client 上增加具体业务适配器；
5. 为每个服务端错误码定义页面行为；
6. 增加契约、过期、撤销、弱网、版本失效和真机测试；
7. 联调记录中固定契约版本、B SHA、X SHA 和 test 环境；
8. 通过评审后才允许显式启用，阶段 0 未 `GO` 前仍不得启用生产或交易。
