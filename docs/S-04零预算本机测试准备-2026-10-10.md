## 本机检查与运行边界

运行只读检查：

```powershell
node backend/ops/check-device-test.cjs
```

脚本检查 Node、Docker、cloudflared 和本机 API 健康端点，不读取凭据、不创建资源、不启动服务。2026-10-10 检查确认 Node v24.18.0、Docker Engine 29.7.2；cloudflared 不在 PATH。受限执行环境可能无法访问 Docker 管道，不应直接认定 Docker 未运行。

现有 `backend/compose.yaml` 仅作本机依赖参考，保留 localhost 绑定。下一步建立隔离测试配置与独立数据卷，再启动 API/Worker；不要把数据库、Redis、对象存储管理端口或示例凭据暴露到公网。真实微信密钥仅存本机忽略配置，不发送到聊天、不进入 Git。

## 本机启动结果与操作

本轮使用 `tingyue-device-local` 专用 Compose project、独立持久卷与随机凭据。配置写入 Git 忽略的 `backend/.env.device-local`，再次运行生成脚本会保留已有密钥。对象存储复用本机已有 AIStor 镜像和 `minio.license`，没有开通新服务或接受新协议。

- PostgreSQL：`127.0.0.1:55433`；Redis：`127.0.0.1:56379`；对象存储：`127.0.0.1:59000`，管理界面 `127.0.0.1:59001`。
- API：`http://127.0.0.1:3100`；微信身份模式 `stub`，不代表真实微信登录成功。
- 10 个迁移已应用至新测试库。`/health/live` 返回 `ok`；`/health/ready` 返回 `ready`，PostgreSQL、Redis、对象存储全部通过。
- Worker 队列 ping 通过；S-04 双会话 smoke 通过进度合并、生词删除、重放、账号隔离和退出撤销；积分 smoke 通过历史总分、碎片秒数、跨版本去重、答题去重、撤回与跨月重算、大整数和回滚拒绝。
- API/Worker 隐藏后台运行；本机日志与 PID 在忽略目录 `.cache/device-local/`。测试 smoke 自建并清理随机 schema，不代表手机验收。

以下命令在仓库根目录准备依赖：

```powershell
node backend/ops/prepare-device-local.cjs
docker compose --env-file backend/.env.device-local -f backend/compose.device-local.yaml up -d
```

在 `backend` 目录执行迁移并分别在两个终端启动服务（当前后台进程已运行，勿重复启动）：

```powershell
node --env-file=.env.device-local --experimental-strip-types src/database/cli.ts up
node --env-file=.env.device-local --experimental-strip-types src/api/main.ts
node --env-file=.env.device-local --experimental-strip-types src/worker/main.ts
```

终端启动的服务可用 Ctrl+C 停止；当前隐藏后台进程由 `.cache/device-local/pids.json` 标识，停止前应核对 PID 对应的命令仍是本项目 API/Worker，避免 PID 重用误停。依赖可用以下命令停止，保留数据卷：

```powershell
docker compose --env-file backend/.env.device-local -f backend/compose.device-local.yaml stop
```

上述后端启动阶段没有修改前端 API 根地址、建立隧道、上传微信版本或发布。

本机与 HTTPS 检查均通过：HEAD 200、`audio/mpeg`、2,580,786 字节；前 1,024 字节 Range 返回 206。本机尾段 Range 返回 206，越界 416，POST 405；HTTPS 非音频 API 路径返回 404。

临时地址和日志保存在 `.cache/device-local/tunnel-error.log`，PID 分别保存在 `audio.pid`、`tunnel.pid`；地址不作为稳定配置写入前端。停止对应进程即可关闭入口，停止前需核对进程命令与路径。电脑关机或隧道停止后地址失效。

待用户在 iPhone Safari 验证能打开、播放和拖动；当前仅完成本机 HTTPS 检查，不表示 iPhone 或小程序验收成功。后端 API、数据库及管理入口未通过该隧道公开。

## 本机客户端 API 联调与重复登录修复

用户随后要求暂缓 Android；本轮按用户确认仅准备、验证模拟身份本机接口，不开放公网 API。

发现并修复开发客户端固定 stub 登录码只能用一次的问题：开发环境发送 `test:<固定身份>#<每次唯一票据>`，stub provider 用固定身份绑定用户，票据仍一次性使用；保留旧测试码兼容性。真实微信 provider 与体验/发布环境的真实登录码流程不变。

新增 `tools/device-api-smoke.cjs`，使用实际 `createBackendApi` 和 `createWxTransport`，以 Node fetch 适配 wx.request 连接运行中的本机 API。通过登录、退出、重新登录同一用户、另一个账号隔离、进度读取、积分读取和排行配置读取。该适配器不是微信运行时，未验证小程序合法域名、手机网络或真实微信身份；进度与生词写入合并已有独立 S-04 HTTP smoke 证据。

```powershell
node tools/device-api-smoke.cjs
```

本机测试配置仍是 `backend/.env.device-local`，客户端开发模式默认连接 `http://127.0.0.1:3100`；如开发工具有旧缓存地址，需先核对 `tingyue.dev.apiBaseUrl`。手机上的 localhost 指手机自身，不能用于手机连接电脑。正式账号 AppSecret 仍不配置、不索取到聊天。

修复验证：后端 typecheck 和 60/60 测试通过，客户端 adapter 4/4 通过；运行 API 已重启加载修复。旧音频预览二维码对应旧构建，不能作为此 API 修复的设备证据。

公网 API 尚未建立。后续先设计测试身份访问限制和路由范围，形成可检查配置，再向用户确认具体开放范围；此前单 MP3 的授权不涵盖 API。
