# 模拟收费验收与操作

2026-10-10。本轮已完成本机模拟订单、付款确认、固定版本授权、全额退款、订单页面和自动验证。不会扣款。尚未接入微信支付，不代表正式收费可上线。Peter Rabbit 保持免费。

## 已实现

- 原创测试内容包 `commerce-test-bundle@1`，模拟价格 ¥1.00 / 100 分，一次购买固定内容版本，无优惠券或赠送。测试文本和 10 秒静音 WAV 独立存储，不作为付费正文打进客户端。
- 订单金额与内容列表从服务端取得，订单保存不可修改的快照。客户端不能提交金额、付款状态或其他用户 ID。
- 同一账号、同一幂等键并发创建只得到一笔订单；换商品复用键返回冲突。订单列表只返回本账号最近 100 笔。
- 仅本机 CLI 可以确认模拟付款或全额退款，无付款/退款 HTTP 路由。事件幂等，金额必须匹配；退款后重复旧付款事件不会恢复授权。
- 受限作品和单篇均校验权益。未付款不能取得 Manifest，也不能新增进度、生词或小测；有另一笔有效订单时保留权益。退款保留学习记录和积分，已有生词仍可删除，已确认请求重放返回原回执。
- 固定购买的 v1 在 current 切换 v2 后仍可取得 v1 Manifest、提交 v1 进度、小测和生词。新增版本没有自动赠送给旧订单。撤下的内容仍不允许读取。
- 学习写入对授权订单持共享锁，与退款串行。已签发的资源 URL 最多有效 5 分钟；退款无法收回此前已经下载或缓存的内容。
- 模拟接口只注册于 local/test 环境。现有公网受限网关不开放这些新接口；普通包默认隐藏测试入口。

## 本机操作

在微信开发者工具中导入以下项目，使用开发者工具模拟器；localhost 地址不能供另一台手机访问。账号仍为明确标记的模拟身份。

- 主账号项目：`C:\demo11\peter-rabbit-content-pipeline\build\commerce-local-primary`
- 隔离账号项目：`C:\demo11\peter-rabbit-content-pipeline\build\commerce-local-isolation`

进入 Me，登录测试账户，点击“模拟内容包与订单 · 不收费”，创建订单并复制订单 UUID。在仓库根目录 PowerShell 执行（将 UUID 替换为复制的订单号）：

```powershell
& C:/nodejs/node.exe --env-file=backend/.env.device-local --experimental-strip-types backend/scripts/simulated-commerce.ts pay UUID test-pay-唯一编号 100
```

页面“刷新订单”后显示“已授权”，点击“检查此版本访问权限”。全额退款命令：

```powershell
& C:/nodejs/node.exe --env-file=backend/.env.device-local --experimental-strip-types backend/scripts/simulated-commerce.ts refund UUID test-refund-唯一编号 100
```

退款后刷新并再次检查权限。当前页面用于订单及授权验收；完整付费阅读器、正式商品运营页面属于后续接入，不应把它视为正式商城。

重建两个测试项目：`node tools/build-commerce-local-preview.cjs`。准备原创测试样本：同一 env-file 下运行 `backend/scripts/simulated-commerce.ts seed`。现有本机 API 已启动，样本和 0011 迁移已应用；脚本拒绝其他数据库地址。
