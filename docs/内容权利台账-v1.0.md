# 内容权利台账 v1.0

> 建立日期：2026-09-20  
> 用途：正式发布前逐项记录文字、翻译、插画、封面、录音、合成语音、题目与词卡的来源及商业使用结论。  
> 当前结论：**没有任何作品获准正式商业发布。**

本台账是项目核验记录，不是法律意见。“公共领域”“原创”“来自 LibriVox/Project Gutenberg”都不是自动放行条件；必须核对具体素材、版本、目标经营地区、商标/平台条款和证据链。批准人不得只依据本表中的来源描述签字。

## 1. 状态规则

| 状态 | 含义 |
| --- | --- |
| `SOURCE_RECORDED` | 已记录来源，但商业权利、目标地区或具体素材尚未全部核验 |
| `NEEDS_EVIDENCE` | 缺少合同、授权、创作记录、许可文本或素材对应关系 |
| `NEEDS_REVIEW` | 证据存在，等待具备权限的审核人作结论 |
| `APPROVED` | 具体素材、用途、地区、期限和署名要求均已核验并签字 |
| `REJECTED` | 不允许用于正式发布，须替换或移除 |

## 7. 每项批准必须填写的字段

| 字段 | 要求 |
| --- | --- |
| 素材唯一标识 | work_id、piece_id、文件名及 SHA-256 |
| 来源 | 原始 URL、合同/采购单/创作记录或受控证据编号 |
| 权利主体 | 作者、译者、插画者、朗读者、生成工具账号主体等 |
| 授权范围 | 商业/非商业、复制、改编、信息网络传播、再许可、收费访问 |
| 地域与期限 | 实际上线地区、开始/结束日期或永久 |
| 署名与附加条件 | 展示位置、许可文本、商标限制、退款或源文件提供要求 |
| 审核结论 | `APPROVED` / `REJECTED`、审核人、日期、备注 |

任何一项缺少具体素材对应关系、目标地区或审核人时，不得标记为 `APPROVED`。
