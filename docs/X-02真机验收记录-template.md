## 3. 存储抽查

抽查 `tingyue.product.v1.progress['peter-rabbit-01']`：

- `checkpointSeconds` 只在连续正常播放满 5 秒后推进；
- `listenedRanges` 不跨越拖动区间，重复区间会合并；
- `completed` 仅在自然结束、唯一覆盖率至少 90% 且尾部 3 秒已听时为 `true`；
- `schemaVersion` 为 `2`，`contentVersion` 与当前内容一致；
- 系统暂停、缓冲和异常长间隔不会产生明显虚增。
