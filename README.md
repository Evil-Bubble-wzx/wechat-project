# 芽芽听阅 · 微信小程序前端雏形

## 直接查看

1. 在微信开发者工具中打开或导入 **C:\\demo11**。
2. 项目类型选择“小程序”，使用现有 AppID；如果无权使用，可换成自己的 AppID 或工具提供的测试号。
3. 点击 **编译**，启动页面为 `modules/listen-read/pages/home/index`。

无需安装依赖、无需后台、无需配置网络域名。音频和插画已经生成并附带在项目中。

## 建议体验顺序

- 首页点击“免费听一章”，进入《小兔的种子》的第一章。
- 点播放：真实英语合成音频、句子同步高亮；可切换译文、倍速、上一句/下一句、拖动进度。
- 点击 `seed` / `rabbit` 等单词：自动暂停，显示音标、词性、释义、原句，可收藏到单词花园。
- 返回图书详情，选择第二章或“解锁整本”，点击“模拟购买”。不会扣款。
- 完成阅读小测，查看逐题解释和成绩。
- 在“书架”和“我的”查看已购书、最近阅读、生词与学习记录。

## 本次范围

3 本原创示例短故事，每本 2 章；6 段真实合成音频，24 句配套中英原文；每章 3 道示例题。示例章节刻意较短，便于快速体验完整流程。

本版仅模拟购买，不接真实支付、登录或服务器。购买、进度、生词与成绩存储在本机；换设备不同步。播放采用前台音频，离开听阅页会暂停；本版不承诺后台或锁屏播放。学习统计来自本机实际操作，不预填虚假成绩。

插画由项目绘图脚本生成；故事为原创示例，音频使用本机 Microsoft Zira 英语合成语音。正式商业内容需另行制作或核对授权。示例报价仅展示，不构成收费配置。

## 项目结构

```text
modules/listen-read/
  pages/          首页、书架、我的、图书详情、听阅、小测、单词花园
  components/     可复用图书卡片
  services/       内容访问、本机存储、宿主适配、播放封装
  content/        故事、句子时间轴、词典（JSON 源文件与生成的 JS）
  styles/         共用样式
assets/           本地音频、封面、插画与图标
tools/            内容生成与验证脚本（不打包到小程序）
docs/             交付说明与后续实现建议
```

已有 `pages/index`、`pages/news`、`pages/logs` 示例文件保留，但不再作为启动入口。

## 维护与验证

修改 `content/*.json` 后，运行 `node tools/build-content.js` 生成原生小程序可加载的 JS 数据模块，然后重新编译。JSON 本身不能直接通过小程序 `require()` 加载。

重新生成示例素材（本地已附带，普通预览不需要执行）：

```powershell
./tools/make-audio.ps1
python tools/assemble-audio.py
python tools/make-art.py
node tools/build-content.js
node tools/check.js
```

音频生成依赖 Windows 已安装的 Microsoft Zira 语音，插画生成依赖 Python Pillow。自动检查覆盖首章权限、模拟购买、进度与生词存储、题目评分、路由、词典覆盖和素材引用；微信开发者工具内另做实际界面与播放检查。

## 后续接入正式产品

当前本地内容数据是前端演示夹具。要实现“新增书不发版”，需将 `services/content.js` 改成远程内容接口，并实现内容管理与发布服务。模块仍需接入宿主路由与资源路径；目前并未声称已在第二个小程序完成移植验证。

正式购买需要服务端订单、权益校验及受保护音频/原文接口；不能使用本机“已购”状态保护付费内容。后台音频、支付适用范围、内容授权等需在上线阶段按微信当时规则核对并真机验证。
