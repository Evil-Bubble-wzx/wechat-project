# 听阅 UI 规范

## 视觉方向

保留 MegaWords 的搜索、书目封面、数据标签、阅读卡、实体借阅入口、听读与测验双入口。使用低饱和的自然配色与简洁线性图标；主要导航、栏目、按钮和书目信息使用英文，保留中文说明及中英释义。图标、六张样例封面均为本项目绘制的原创 SVG，运行时使用导出的 PNG，未裁切原截图作为页面。

## 设计标记

| 用途 | 规范 |
|---|---|
| 主色 | #2C6C50 深青绿 |
| 页面背景 | #F7F8F5 暖白 |
| 主要文字 | #253A32 |
| 次要文字 | #65745F |
| 内容背景 | #E9EDDC 浅苔色 |
| 点缀 | #CC7956 陶土色 |
| 大标题 | 21–24px；故事宣传标题使用衬线字体 |
| 常规内容 | 13–16px；说明信息至少 11px |
| 主要按钮 | 高度至少 44px；可见禁用态 |
| 页面边距 | 20px；卡片圆角 10–14px |
| 布局单位 | 原生 rpx；浏览器预览转换为 CSS px |

## 交互

底部仅 Home / Recent / Me 三个 Tab。Find Books 和 Borrowed 是 Home、Me 内的二级入口。首页只展示一个 Books 列表，删除重复推荐区；列表统一采用左封面、右标题、By 作者、Series 来源系列、Lv 等级及 No. / Words / F/NF / Pages 双列元数据。详情页并列展示 Read for Me / Take Quiz，实体预约在独立借阅区。登录页提供 WeChat Login / Phone Login 切换、协议勾选与演示说明。预约前检查账户和库存，确认弹层展示地点、期限和取书方式。没有记录的页面展示明确空状态，不用虚构业务数据填满。

播放器采用深色背景，聚焦封面与播放控制。字幕默认关闭，点词打开词卡并暂停音频。反馈使用 toast 或底部弹层。交互预览支持键盘焦点、输入标签和减少动态效果的系统偏好。

## 后续实现注意

实际微信胶囊由系统提供；浏览器预览单独显示模拟胶囊。后台播放、不同机型安全区域、读屏标签和真实登录授权需在微信开发者工具及真机进一步验证。该版没有宣称已通过完整无障碍认证。
