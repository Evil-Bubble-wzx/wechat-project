# ADR 0003：Quiz 排行综合得分 v1

- 状态：Accepted
- 日期：2026-09-24
- 规则版本：`quiz-score-v1`
- 业务时区：`Asia/Shanghai`

## 决策

榜单按服务端计算的 0～1000 整数综合分排序，API 指标固定为：

```json
{ "key": "rankingScore", "label": "Quiz Score", "value": 782, "unit": "points" }
```

客户端不得计算、覆盖或上传该分数。每个榜单快照必须记录规则版本、筛选条件、统计窗口和生成时间。

## 数据边界

1. 只使用统计窗口内合法的`server_verified` Quiz attempt。
2. 每名用户、每个`work_id`只采用该周期内第一次验证成功的attempt；后续重做保留在明细中，但不改变榜单分，防止刷题。
3. 校区、年级和阅读级别使用服务端已验证档案。
4. 内容词数、内容级别和Fiction/Nonfiction来自已发布内容版本，不能接受客户端上报。
5. 同一筛选组合形成一个比较人群；不同校区、年级、级别或周期的分数不可直接横向比较。

## 六项特征和权重

| 特征 | 权重 | 原始值 |
|---|---:|---|
| Quiz Completion | 30% | 完成Quiz的不同书本数 |
| Reading Volume | 15% | 不同书本正式词数总和的`log1p` |
| Accuracy | 25% | 首次attempt正确率，使用3本、70%的先验做贝叶斯校正 |
| Challenge | 15% | 书本级别减用户阅读级别，逐本限制在`-1.5～1.5`后取平均 |
| Growth | 10% | 至少6本时，后半段平均正确率减前半段平均正确率 |
| Breadth | 5% | Fiction与Nonfiction越均衡越高；至少需要2本有分类书目 |

每项原始值转换为当前比较人群内的midrank百分位`P_i`。缺少级别、成长或题材数据时，该项取中性百分位`0.5`，不编造数据，也不因内容元数据缺失奖励或惩罚用户。

```text
score = round(1000 × (
  0.30 × P_completion +
  0.15 × P_words +
  0.25 × P_accuracy +
  0.15 × P_challenge +
  0.10 × P_growth +
  0.05 × P_breadth
))
```

结果限制在`0～1000`。同分用户采用并列名次；展示顺序再按完成书本数、贝叶斯校正正确率和匿名participant ID稳定排序，这些字段只用于同分展示稳定性，不改变名次。

## 百分位规则

对每项特征升序排列。相同值共享其位置区间的中点百分位；全员相同时该项所有人均为`0.5`。这样不会因完全相同的数据人为拉开差距。

## 发布门槛

- 少于10名合格用户时返回`cohort_too_small`，不返回可识别排名。
- 用户至少完成1本Quiz书才能进入比较人群。
- 聚合必须可由原始attempt和内容版本全量重算，并生成不可变快照。

## 解释性

排名明细页展示六项得分拆解、完成/全部书目统计和逐书Quiz记录。正确率是算法输入之一，不等于最终排名分；客户端文案必须明确算法版本和统计周期。
