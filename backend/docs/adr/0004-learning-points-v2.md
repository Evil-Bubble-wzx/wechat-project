# ADR 0004：累计学习积分 v2

- 状态：Accepted；2026-10-10 用户确认，`DONE_LOCAL_TEST`，生产部署待验收。
- 取代：ADR 0003 的 `quiz-score-v1`，旧快照保留。
- 契约：`api-contract-v2.0.0`；业务路径仍为 `/api/v1`。

有效听读每满秒 1 分，稳定篇目首次完成 50 分，同题首次服务端确认答对 10 分；无业务上限，服务端精确整数计算、API 十进制整数字符串。客户端不能上传或伪造可信积分。

跨版本按稳定篇目秒数最高值去重，首次完成和逻辑题奖励不重置。历史迁移和 S-01 本机旧记录导入积分只进入个人累计，不进入期间榜。期间榜按新增事件的服务端时间聚合；校区/年级/级别仍来自已验证档案，小样本不展示名单。

撤回或无效答案不再支持积分；如果同题仍有其他有效正确答案，该积分保留。后来首次恢复有效正确答案时恢复原事件及原期间，不重复计分。答案支持关系变化追加 outbox 重建，允许累计积分下降。旧事实再次出现时重新激活原快照，内容和游标绑定不变。

Quiz 整份答卷提交后确认积分；幂等重提保持答卷判分，但附带累计积分摘要是实时查询。跨版本并集匹配、实时逐题上传、真机与生产资格不在本轮完成范围。

实际验证与运行入口见 [2026-10-10 验收交接](../../../docs/学习积分验收与交接-2026-10-10.md)。
