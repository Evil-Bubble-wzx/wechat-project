# ADR-0002：环境边界

- 状态：已确认 local/dev/test，prod 待阶段 0
- 日期：2026-09-24

| 环境 | 用途 | 数据 | 允许事项 | 禁止事项 |
| --- | --- | --- | --- | --- |
| local | 单人开发与自动测试 | 本机测试数据 | Compose、测试密钥、重建 | 真实用户、真实支付、正式发布 |
| dev | 团队联调 | 脱敏或合成数据 | 契约联调、失败注入 | 生产密钥、正式内容发布 |
| test | 验收和压测 | 受控候选内容 | 批量导入、恢复演练 | 真实交易、绕过审核门槛 |
| prod | 正式运行 | 真实业务数据 | 阶段 0 `GO` 后按审批启用 | 使用 local 默认凭据或测试身份 |

环境使用独立账号、数据库、Redis、bucket、域名、密钥和日志。生产配置只通过受控密钥系统提供，不提交 `.env`。
